# Kigurumi 头壳尺寸自动计算与验证工具链

## 🌟 简介
这是一个专门为 Kigurumi 玩家和头壳制作者设计的开源工具箱。
它的核心目的是：解决二次元立绘（2D）向真实人类穿戴（3D）转化时的**比例悖论**。

它可以帮你从角色立绘中自动提取比例，并结合演员的真实身体数据，逆向计算出既能完美还原角色视觉效果，又保证演员能舒舒服服戴进去的头壳 3D 建模基准尺寸。

## 🧰 工具列表
1. `char_ratio_from_image.py`：立绘比例自动提取脚本（输出头身比 `N`、头宽/肩宽 `r`）
2. `kigurumi_head_calc.py`：头壳物理可行性与尺寸计算主程序
3. `gui.py`：PySide6 图形界面，左右两栏跑完「立绘分析 → 尺寸测算」全流程
4. `kigurumi_colab.ipynb`：供 Colab 或本地运行的 Jupyter Notebook 交互版

## ⚠️ 痛点与核心逻辑（为什么你需要这个工具？）
很多新手在定制或自制头壳时，会强行要求建模师按照立绘的“8 头身、0.5 头宽比例”来建。
但在真实世界中，**人类的肉身头骨大小是固定的**（普通成年人头高约 25cm）。如果你要求一位 190cm 高的演员呈现 8 头身，那么最终头壳的外部总高（包含厚厚的假发）只能有 23.7cm——这甚至比演员的原生脑袋还要小，物理上根本塞不进去！

本计算器严格按照物理层级进行尺寸链堆叠：
**演员肉体 -> 海绵缓冲层与空气余量 -> 树脂硬壳（建模外壳） -> 假发厚度 -> 最终视觉外观** 

如果推算出的建模净壳比演员的头还要小，程序会立刻亮起红灯（❌不通过），并给出物理层面的破局建议（比如：需要垫多厚的肩、需要穿多高的高跷、或者应该将头身比妥协到多少）。

## 🚀 快速开始

### 环境依赖
系统要求 macOS / Linux / Windows，需安装 Python 3。
```bash
# 安装基础图像处理库（opencv 用于人脸锚定；务必 <5.0，5.x 已移除 CascadeClassifier）
pip3 install Pillow "opencv-python<5.0.0"

# 【强烈推荐】安装 AI 抠图模块，解决 99% 的背景与 UI 干扰问题
pip3 install rembg onnxruntime
```

> 若运行 `char_ratio_from_image.py` 时看到「OpenCV 5.x 已移除 cv2.CascadeClassifier」
> 的告警，说明人脸锚定没生效，会退回较粗的纯剪影法。按上面装 `opencv-python<5.0.0` 即可。

### 第一步：从立绘提取二次元比例
找一张角色站立的正面立绘（游戏截图也可以），运行：
```bash
python3 char_ratio_from_image.py 你的角色立绘.png
```
**✨ AI 新特性**：只要安装了 `rembg`，脚本就会在底层自动调用 U-2-Net 神经网络剥离复杂的背景、截图 UI 和水印，精准提取纯净的角色剪影进行运算。

**识别原理**：先用剪影「宽度剖面」+ 动漫人脸框定位 头顶 / 下巴 / 颈 / 肩 四条线，再反推比例。它**每次都会输出 `<原名>_analysis.png` 标注图，务必看一眼再用结果**。

**避坑指南（谨防视觉欺骗）**：
- **下巴 / 头高（最不稳的一环）**：长发盖住脖子、兽耳、帽子都会干扰。若标注图里下巴线明显不对，用 `--chin-y 像素`（按原图坐标）手动覆盖：
  ```bash
  python3 char_ratio_from_image.py 立绘.png --chin-y 66
  ```
- **假肩宽**：蓬松长发、机甲、袖子、毛领、披风会让剪影肩宽严重高估（脚本会在这类情况报警：肩宽 > 头宽 ×2.2，或肩比头还窄）。要的是角色的**素体骨架肩宽**；正常萌系少女头肩比约 `0.65 ~ 0.70`，自动值明显偏离就用 `--shoulder-w 像素` 手动给。
- **想更准，用骨架**：加 `--pose` 会用 YOLO 姿态模型取「肩峰关键点」量肩宽（定义上和主脚本的 `shoulder_width` 一致）、用踝点约束脚底线——对披风 / 毛领角色通常比剪影准。需额外安装：
  ```bash
  pip3 install ultralytics
  pip3 install "opencv-python<5.0.0"   # ultralytics 可能把 opencv 升到 5.x，装回 4.x
  ```
  姿态模型是在真人上训的，动漫立绘属域外输入，**常见的失败是把肩点定到脖子 / 衣领上（值偏小）**。脚本会用「肩宽 ≥ 含发头宽 ×1.2 且 ≥ 身高 13%」把关：不通过就自动回退剪影肩线并打印告警（两个值都报出来）。标注图里 **橙色＝实际采用值，紫色＝骨架值**，对不上就说明骨架这次跑偏了。
- **头宽**：默认用「人脸框宽 × 1.45」封顶，防止毛领 / 双马尾撑爆。宽发角色可 `--head-cap 1.6` 调大，窄脸调小。
- **人脸锚定失败**：若看到 OpenCV 版本或未安装相关告警，脚本会退回纯剪影法（精度差很多），按上面的依赖装 `opencv-python<5.0.0` 即可；也可以用 `--chin-y` / `--head-w` / `--shoulder-w` 手动覆盖，或加 `--json` 拿结构化结果。

### 第二步：计算最终 3D 建模尺寸
拿到满意的头身比（N）和头肩比（r）后，结合演员真实数据进行最终推算：
```bash
python3 kigurumi_head_calc.py \
  --height 190.0 --weight 84.8 --shoulder-width 45.0 \
  --head-width 18.0 --head-height 25.0 \
  --ratio 6.15 --head-shoulder 0.68 \
  --wig 2.5 --mount chin
```

脚本会输出极其详尽的硬核报告，包含：
1. **净壳（建模用）三维包围盒**：直接发给建模师，或填入 Blender / ZBrush 作为基准约束。
2. **可戴性校验**：XYZ 三个轴向的穿戴余量（负数代表卡脑袋，必须修改比例）。
3. **眼位与视野分析**：精准预测演员眼睛位于面罩的百分比位置。平视能不能正好对上角色的眼窗？一目了然。
4. **外挂优化建议**：如果当前比例做不出来，系统会告诉你需要外挂多厚的“垫肩”，或者踩多高的“内增高/高跷”。

### 第三步（可选）：图形界面一条龙
不想敲命令就跑：
```bash
python3 gui.py
```
左栏选立绘 → 「开始分析立绘」，识别到的 `N` / `r` 会自动同步到右栏；右栏填演员实测数据 → 「计算 3D 建模尺寸」即可。

> `char_ratio_from_image.py` 的告警（例如人脸锚定失败）会一并显示在左栏输出里，别忽略。
